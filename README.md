# Cariri em Foco

Portal de notícias da região do Cariri, desenvolvido na disciplina **TBD0016 - Programação para Web**.

## Sobre o projeto

O **Cariri em Foco** é um site de notícias construído com HTML, CSS e JavaScript. A proposta é reunir, em um só lugar, notícias da região do Cariri, uma página de leitura de matéria e um painel de dados ("Cariri em Dados") com estatísticas locais.

## Estrutura do projeto

- **`index.html`** — página inicial, com notícia em destaque, grade de notícias e barra lateral;
- **`noticia.html`** — página de leitura de uma notícia completa;
- **`cariri-em-dados.html`** — painel com filtros, indicadores (KPIs), gráficos e tabela;
- **`paginas/integrantes.html`** — página com os integrantes da equipe.

## Responsividade

O projeto foi adaptado para funcionar bem em celulares, tablets e computadores, usando design responsivo com CSS:

- meta tag `viewport` em todas as páginas;
- imagens fluidas (`max-width: 100%`) que se ajustam ao contêiner;
- media queries nos pontos de quebra 1024px, 768px e 480px;
- menu de navegação que se empilha na vertical em telas pequenas;
- grade de notícias que passa de 3 → 2 → 1 coluna conforme a largura;
- sem rolagem horizontal indesejada em nenhuma largura de tela.

## Como visualizar

1. Abra a pasta do projeto no seu computador.
2. Execute o arquivo `index.html` em um navegador.
